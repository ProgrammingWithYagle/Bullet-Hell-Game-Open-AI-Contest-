# Gate Widow baseline and next implementation

Read-only baseline source: `2340c83afc313ba873e04819bd09e99d128f3a31`, protocol 28/content `39ca64136ddb477d344eb75408a22ed239af57efb1d3a3a4f5893ac33c13864d`. No source/preview/count changes are included in this assessment. The guide/Marshal checkpoint is complete separately; the full development goal remains active.

`baseline-gates.json` samples the actual CivicDirector on all six maps/six difficulty cover layouts, three chosen forms and two phases: 216 cases/129,600 ticks/648 gate waves. All 108 paired phase signatures are identical. All 72 paired Brutal/Crazed signatures are identical. All cases keep the signature boss position stationary and use the fixed gate Y=615. Standard cooldown is eight seconds and advanced is 7.2 seconds; the one-open-lane rotation, 1.5-second tell and 3.5-second closure otherwise repeat. Generic phase projectile definitions and shared advanced overlays do differ; this assessment isolates the gate signature.

No sampled open lane is completely blocked at its horizontal center after player-radius inflation. A separate `baseline-ejection.json` checks 2,544 initially clear gate-center standing positions using the actual leaveClosingGates function; none land in static masonry/out of bounds in this sample. These findings do not prove every route/motion/lava/projectile case safe. The sampled baseline does not justify inventing a geometry defect.

Next quality pass should create two distinct gate behaviors suitable for its entry threat, preserving fixed grade/base combat numbers/art/Third Latch theme. Keep the first phase's three readable lanes and rotate the safe opening. The late phase should warn a different axis or a visibly sequenced second closure and move the Widow to a reachable casting station before the new cast. Brutal needs a separate fully warned follow-up through the surviving gate path, with gaps and complete Crazed inheritance. Crazed may add its own separately warned crossing sequence. All new collision, ejection, bounds, actual masonry and lava exclusions must share authoritative/predicted geometry and be sampled on all maps and cover rules. The warning must lock before it harms or becomes solid. No silent safe-lane swaps, teleports, generic projectile double-multiplication or unavoidable newly solid overlap.

Before crediting the eighth quality implementation: integrate real authority/presentation, two phase names/response help in fifteen locales, current build/protocol and bounded known local migration, actual movement/ejection/contact/projectile/cancellation/cleanup/prediction/network tests, full checks, one synchronized ledger/changelog update, exact-source CI and canonical Wiki publication. Freeze a new unused preview; leave 5193 and every old frozen root/process unchanged. Human/rendered/device/native-language/listening/final balance acceptance remains separate.

Run the probes with the bundled Node executable and `--import tsx` from the existing repository working directory, passing the absolute path of each `.mjs` under this folder. Direct native Node loading fails on the existing Marshal JSON imports without the project's TypeScript/JSON loader; no source alteration is needed.
