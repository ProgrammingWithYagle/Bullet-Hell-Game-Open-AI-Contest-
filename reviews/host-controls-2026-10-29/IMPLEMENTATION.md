# Explicit host controls

The user accepted the5239connection/menu flow as pretty clear and requested host password/code visibility, entry reveal buttons, explicit host-only pause/continue, menu/chat independence, continued play after host departure and a separate end-for-everyone choice.

Session keeps a successfully entered invitation password in a JavaScript private field, cleared by close. Its getter returns a value only for the current authoritative host. Promotion uses the same password that participant entered to join. Host waiting/invite views escape the value into a read-only masked field with an eye button; ordinary guests receive no value. Form toggles preserve exact text/caret and never submit. The server still stores salted verifiers only; no plaintext enters state, metadata, lists or save envelopes.

WorldState now carries explicit matchPaused/endedByHost flags. Only ready current-host messages may change them. Menu pause calls still do nothing online. The authority stops journal simulation steps while paused, renews an available lease independently, clears queued input/action state, rejects paused input/votes/purchases, and retains connectivity/chat. The client blocks prediction/input and pauses scene animation only for a real match pause; Solo retains existing behavior. Host loss clears the pause and transfers ownership. A reconnecting former host stays a participant unless promoted again.

End game for everyone is confirmed separately from Leave. The authority stops the run as defeat with a distinct host-ended explanation, clears a pending boss-defeat beat, closes new joins and never awards a clear or campaign victory. Already-earned Endless/campaign records retain their existing qualification rules. Remaining players continue normally when a host simply leaves.

Protocol43 adds network fields; exact issued42local Practice saves pass full existing validation, while signed/server envelopes remain strict. Prior current-version test assertions advance to43; their issued-save fixtures and identity checks remain.

Native UI fixtures and actual two-/three-peer tests cover password visibility/privacy, host command enforcement, simulation/intermission freezing, chat, known-ticket cleanup, leave/transfer, reconnect, terminal results and no synthetic qualifying row. A first focused run exposed an old hardcoded current42assertion. Two reconnect fixture attempts used an invalid browser close code and a consented server leave; a later attempt incorrectly sampled a transient status. The final fixture uses the established transport interruption and records the reconnect event plus authoritative owner. All failed reports remain preserved.

These are software and actual local transport checks, not browser/rendered, human/device, listening/native-language, WAN or final balance acceptance. The broad polish goal remains active. Every earlier frozen preview, package, original asset and raw report stays separate.
