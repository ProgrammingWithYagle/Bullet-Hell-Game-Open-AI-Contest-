# Bounded survivor animation timing

Development build `2026.10.25-motion-timing`, protocol 13. Survivor runs and action poses can now advance between authority patches through a separate bounded drawing clock. The Colyseus room sends patches every 50 ms while the simulation runs at 30 Hz. Previously, six short-dodge poses were sampled only at those patches: a deterministic 60 Hz drawing fixture observed frames **0, 2, 3, 5**, skipping 1 and 4. The same fixture now observes **0, 1, 2, 3, 4, 5**. This is a software timing trace, not a measurement of actual device FPS.

`PresentationClock` never leads the latest snapshot by more than 1.5 simulation ticks (50 ms). It stays monotonic between advancing patches, ignores duplicate observations without restarting their wall-time anchor, holds at the limit during a stall, rejects nonfinite wall-time advancement and resets on run, encounter, phase or backward authority boundaries. Noncombat combat time remains paused. Values are used only to select drawn frames; movement, hazards, damage, inputs, status and the authoritative view remain unchanged.

Authority state still chooses which action is active. Extrapolated elapsed time chooses a frame inside that action and holds the last frame until the corresponding authority transition arrives. It cannot predict a shot, damage, fall, revival or end of a dash. Reduced-motion choices remain stable, and ordinary run timing continues to honor each clip's authored frame rate.

Tank's real Rescue Charge lasts ten simulation ticks. Its animation previously used the seven-tick ordinary dodge interval, holding the first pose for too long. The shared `RESCUE_CHARGE_TICKS` constant retains the existing value from the class rules and is now used for both the authoritative timer and presentation calculation. A real E-input regression checks every tick across the entire charge and sees all six drawn poses at their proportional positions. Ordinary dodge timing and gameplay power remain unchanged.

`tests/presentation-timing.test.ts` adds five checks: the real charge, six-frame visibility with twenty-Hz patches/sixty-Hz drawing samples, duplicate/stall/clock bounds, reset/noncombat boundaries, and reduced-motion/downed/revival behavior without view mutation. The two failing pre-change traces and later focused/full pipeline logs are retained in `reviews/motion-timing-2026-10-25/`. Rendered Phaser transitions, human/device animation feel and final hosted capacity remain open. The seventeen existing Wiki image bytes, production native artwork, issued Windows archive and frozen one-hour endurance measurements retain their separate identities.
