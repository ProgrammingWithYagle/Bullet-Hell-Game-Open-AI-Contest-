## Orders and feedback

Use the Escort/Hold/Focus buttons on every input layout. Default keyboardV and gamepadbutton15 cycle available orders; mappings can be changed. The cycle skips Focus when no valid mark exists. Hold chooses a reachable point up to140units along the actual aim direction, stopping before cover. Focus follows only the current own primary mark and does not silently switch to a nearby enemy. Mark expiry or target loss returns it to Escort. Orders are authenticated, rate-limited and rejected while paused or outside active combat.

The client shows actual owned health, order, permanent/temporary counts, the Hold point and the marked target. Own companions have small health bars and ground outlines; other callers' bodies remain identifiable without duplicating player nameplates.
