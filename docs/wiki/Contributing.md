# Contributing

Work on feature branches and open a pull request. Keep CHANGELOG.md current for player-visible changes and maintain catalog keys/placeholder parity in all fifteen locales. With Node 24/pnpm 11.25.0, run pnpm verify: authored-content validation, strict TypeScript, rules/real-network/HTTP/SQL tests and a production client build.

Canonical Wiki pages live under docs/wiki/; publishing that directory to the native Wiki is a separate operation. The Stage 1 generator can restore design-only wording, so reconcile runtime status after generation. Preserve sealed historical packets and exact evidence. Report authored design, implemented gameplay, synthetic tests, assistant browser review and actual human/device/native-language evidence separately.

Keep credentials and generated dependency/build output out of source control. Main protections and draft PR gates remain in effect; a public development playtest is not the full release.
