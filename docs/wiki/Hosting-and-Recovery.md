# Hosting and recovery

Current state: no server has been provisioned. Free hosting is the initial constraint.

Use a static browser client and Render gameplay service. Verify quota and capacity before deployment. Public games appear in discovery; private codes do not. A 60 s reconnect window reserves a seat. Signed intermission checkpoints expire after 24 h and allow compatible restart recovery. LAN hosting starts only when selected. Offline solo must not require internet access.

Hosting commands and verified download links are published when those artifacts exist. No paid provisioning is authorized.
