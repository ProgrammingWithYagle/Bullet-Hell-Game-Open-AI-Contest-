# Lessons from the contest stretch

Keep words literal and labels visible. New players preferred Tutorial, New here? and Start gently to poetic or symbolic wording. A practical equipment case, coins and skill manual now support text instead of replacing it. Grave Accord stays one title across languages. Automatic names follow the current language before a fresh setup, then stay stable throughout that setup; typed names are never translated.

Menus need ownership and lifetime, not just styling. Retain focus and scroll after redraw; dispose old controls; abort requests when leaving; preserve drafts and show confirmed purchase/chat errors. Equipment empty details must follow the selected tab. Device and online record filters stay separate. Reuse the downloaded own-result roster only within its active filter generation.

A public IP is not one player. The old 30-lookup code limit blocked large groups on shared connections. Separate known and unknown codes, allow group retry capacity, retain bounded request limits and ignore untrusted forwarded headers. Test actual SDK clients and HTTP, not only unit counters.

Profile a failed load test before changing timeouts. Two 50-client replacement attempts stalled the single coordinator. Its profile showed repeated schema toJSON plus explicit field reads dominating CPU. A one-line conversion correction preserves every wire/build field in a seven-class real-peer regression and passes fresh8/16/50 progression. These local timings are not physical-device FPS proof. The older historical join timeout remains of unproven cause.

Preserve failed evidence. Gate01 caught a Vite-only asset import in pure HUD markup; the helper now accepts URLs. Failed gate01, both large-team attempts, profiles and original frozen bundles are retained. Gate02 and final gate03 bind distinct candidates. An original verifier property typo is corrected by a separate verifier03 without altering the frozen input.

Never use deep equality on a circular DOM graph just to test identity. A previous assertion expansion consumed 13 GB; compare identity with a boolean assertion. Native DOM fixtures must model select-option replacement correctly.

Publication has several independent identities: game source commit, audience, content/protocol, compiled artifact, Site source commit/version and live backend. The old public Site is protocol 4; the final game is 43. Keep testing tools out of public main and worker, and verify emitted bytes and catalogs. A source push is not deployment.

Sites account access is separate from public viewing. The original Site was inaccessible from the connected account; the user authorized a separate public copy. Keep both opaque IDs exact, and do not recreate a Site after a credential failure. Renew short-lived credentials and pass them through hidden stdin only. Never include credentials in this handoff.

Updating Render environment variables already starts a deployment. An extra trigger queued an unnecessary second attempt; both failed on an old corepack-enable command attempting to unlink read-only /usr/bin/pnpm. The new Free server uses corepack pnpm directly, with auto-deploy off, eight slots and one room. Keep deployments and source CI separate.

Free-host local SQLite works for live server records but is lost on sleep/restart/redeploy. Long-term global leaderboards need durable storage. Larger local admission/progression does not establish a larger Free-host capacity. Keep the actual eight-player cap until measured hosted validation supports changing it.

Software verification is not human acceptance. Browser automation remained disabled. Preserve open rendered, native-language, device/controller, listening, balance, physical LAN, WAN and endurance gates instead of claiming zero bugs. Freeze contest scope and begin post-contest expansion only after the new chat receives a fresh request.

The first full-media Sites Git upload returnedHTTP413. Preserve its local Git history; do not recreate the Site or force-push. A smaller publication source keeps the client code plus pinned full-game source/build instructions and SHA256 manifest, while the deployment archive still contains every media file. This separates Git transport limits from the player download.

Sites also limits archive uploads to 512 MiB. The original 688 MB archive retained duplicated WAV music masters as well as 67 compressed primary tracks. The final 210877258-byte archive keeps every primary track and sound effect, and points WAV fallbacks at SHA-bound source files on the pinned GitHub commit. All 18 compiled JS files match the prior public build after reversing only 67 master-URL substitutions. No music composition, UI or gameplay changes. Native archive ingestion normalizes tar metadata, so its returned content hash differs from the original local tar/gzip hash; verify unpacked members and retain both identities instead of assuming format-byte equivalence.
