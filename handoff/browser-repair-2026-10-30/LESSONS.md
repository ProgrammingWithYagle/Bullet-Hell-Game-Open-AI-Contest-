# Browser repair lessons

- An embedded preview does not establish Firefox or Safari compatibility. Audio feature support must be checked at runtime. The music failure was reproduced by omitting cancelAndHoldAtTime from the actual AudioBus test context: the menu track played, then the first crossfade silently failed. Feature detection and scheduled-value fallback fix that path.
- Fit the arena once. Phaser now resizes its canvas to the window and a uniform camera scale fits the complete art bounds. Pointer coordinates use the actual canvas rectangle and the same current projection. Keep all66boss and172survivor clearance policies intact.
- A middle flex item is not necessarily screen-centered. Equal outer side tracks and equal inner heading tracks center the boss panel/name independently of host buttons and encounter text. On narrow windows the panel gets its own row. Test the hidden-panel defeat state as well.
- Generated changelogs are derived from src/shared/update-history.json by tools/sync-changelog.mjs. An initial manual edit after a passing local gate failed CI. The failed log and source candidate are retained; the corrected history was regenerated before gate02. Apply the same rule to generated development-progress documents.
- A full gate must run after all bound source, tool and generated-document changes. Exact-source CI is a separate check; do not call an older passing run current.
- Sites normalizes a static build/ directory to dist/ in its archive and rewrites only the static.directory hosting field. Verify every static file byte and that precise metadata normalization; do not assume the source directory survives packaging unchanged.
- Commit immutable binary assets separately from smaller static delivery when hosting limits require it. All67compressed primary tracks remain local; original-master fallback URLs are source-pinned and hash-verified. Never drop themes to fit an upload.
- Native API/controller/geometry/hash/network checks are useful evidence, but they do not establish rendered Firefox, Safari, Chrome, physical-device or listening acceptance. Browser automation remains disabled; do not bypass it with another browser path.
- The Free server's eight total slots and one-room cap are deployment settings, separate from mode limits: campaigns8, Raid16, Endless50. Raising a setting is not performance certification. No capacity increase, paid hosting, server redeploy or storage upgrade was authorized by this repair.
